### Description

```
Dictionarium Sinicum is an open multilingual Chinese dictionary comprising
428,292 headwords with 11.8M definitions across 18 target languages
(Arabic, Czech, Dutch, English, Estonian, French, German, Greek, Hindi,
Hungarian, Indonesian, Italian, Japanese, Korean, Malay, Persian, Polish,
Portuguese, Romanian, Russian, Spanish, Swedish, Tagalog, Thai, Turkish,
Vietnamese). It merges seven community-maintained dictionaries
(CC-CEDICT, HanDeDict, CFDICT, CC-CIDICT, CHEDICC, Wiktextract, JMdict)
with glosses generated by a single open-weight large language model
(MiniMax M2.5) via a three-phase pipeline: batch translation, retry,
and context-aware backfill. Total API inference cost was ~$146 at
published pay-as-you-go rates. The release additionally includes 511K
Cantonese and Hokkien dialect forms.

The database is a single SQLite file (~2 GB) with the following core
tables: headwords (428,292 entries), definitions (11.8M rows keyed by
headword_id + language + source), and dialect_forms (Cantonese/Hokkien).
Full schema documented in the accompanying code repository.

Companion paper: "Dictionarium Sinicum: A Multilingual Chinese Dictionary
Built by a Single LLM Pipeline" (Uy, 2026). Under review at ACL Rolling
Review, October 2026 cycle. Preprint / camera-ready DOI will be added
here on publication.

Code and documentation:
https://github.com/loqu8/dictionarium-sinicum
```

## Notes

- Zenodo's free tier permits datasets up to 50 GB per record. 2 GB is well within limits.
- Upload via browser (drag-drop) or via API with a personal access token. Browser upload for 2 GB typically takes 5–30 minutes on a normal home connection.
- Zenodo assigns two DOIs: (a) the "concept DOI" that always resolves to the latest version, and (b) a "version DOI" specific to v1.0.0. Cite the CONCEPT DOI in the paper — it survives future updates.
- If the paper is accepted, we can update the Zenodo record (`New version`) to include the final camera-ready as a related identifier.
